# ОГЭ English

**Сайт:** https://shpargalka-ai.github.io/oge-english/

Сайт для подготовки к ОГЭ по английскому языку: решаем официальные задания из открытого банка ФИПИ, отмечаем результаты, следим за прогрессом и разбираем ошибки. Интерфейс — как у [ИИ-Шпаргалки](https://shpargalka-ai.github.io/ii-shpargalka/).

## Страницы

- **Главная** — дни до экзамена, сколько решено, процент верных ответов, серия дней занятий, разделы экзамена с прогрессом.
- **Решаем** — задания из открытого банка ФИПИ по разделам (аудирование, чтение, грамматика, лексика и словообразование, письмо, говорение) прямо на странице. Банк сам проверяет ответ кнопкой «Ответить». Рядом — бланк: отметить задание по коду («Верно» / «Ошибка»), таймер как на экзамене, счётчик слов для письма, открыть задание по коду.
- **Мой прогресс** — статистика по разделам, «Работа над ошибками» (задание открывается снова одной кнопкой), история, отчёт для учителя в .txt.
- **План подготовки** — пункты по разделам «Не начато → Тренирую → Готово», дата экзамена и счётчик дней.
- **Об экзамене** — структура ОГЭ, номера заданий, баллы, время, критерии письма и устной части (по демоверсии и спецификации ФИПИ 2027).

## Откуда задания

Задания **не копируются** на сайт: страница «Решаем» показывает открытый банк ФИПИ (oge.fipi.ru) во встроенном окне. Поэтому задания всегда актуальные, с аудиозаписями и проверкой ответов от ФИПИ, — но для них нужен интернет. Если на каком-то устройстве банк внутри страницы не открывается, есть кнопка «В новой вкладке».

Настройки банка — в `js/data.js` (`window.BANK`): номер проекта, разделы кодификатора, по которым отбираются задания, и количество заданий в каждом разделе (на 10 ноября 2026 года).

## Где хранятся отметки

Только в браузере, на котором занимаются (`localStorage`, префикс `ogeen:`). Регистрации и сбора данных нет. Чтобы перенести результаты учителю, на странице «Мой прогресс» есть кнопка «Отчёт для учителя (.txt)».

## Как открыть у себя

Двойной щелчок по `index.html`. Для заданий из банка нужен интернет.

## Как обновить сайт в интернете

Изменения загружаются в репозиторий `shpargalka-ai/oge-english` на GitHub — через минуту-две они появятся по той же ссылке. Если добавили новый файл — впишите его в `sw.js` (список `FILES`) и увеличьте `VERSION`.
