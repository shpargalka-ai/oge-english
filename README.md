# ОГЭ English

**Сайт:** https://shpargalka-ai.github.io/oge-english/

Помощник для подготовки к ОГЭ по английскому языку с нейросетью (GigaChat, Алиса AI, DeepSeek). Сделан на основе [ИИ-Шпаргалки](https://shpargalka-ai.github.io/ii-shpargalka/).

Сайт **не** обращается к нейросетям сам и **ничего никуда не отправляет**: он собирает хороший запрос (промпт), его копируют одной кнопкой и вставляют в чат.

Что есть на сайте:

- **Конструктор промпта** — раздел ОГЭ, что нужно (объяснить, дать задания, проверить, разобрать ошибки, план, устная тренировка), тема, уровень, время, как объяснять. Пустые места подсвечиваются жёлтым.
- **20 готовых промптов** по всем разделам: аудирование, чтение, грамматика, словообразование, письмо, устная часть, план и разбор пробника, плюс «правки» для доработки ответа ИИ.
- **План подготовки** — пункты по разделам с отметками «Не начато / Тренирую / Готово», общий прогресс, счётчик дней до экзамена и серия дней занятий.
- **Об экзамене** — структура ОГЭ, номера заданий, баллы, время, критерии письма и устной части.
- **Как учиться с ИИ**, **Безопасность**, **Мои промпты** и избранное.
- Работает **без интернета** после первого открытия, печатает промпт и чек-лист, показывает QR-код.

## Откуда данные об экзамене

Из демоверсии, спецификации и кодификатора ОГЭ-2027 по английскому языку (проект ФИПИ, изменений по сравнению с 2026 годом нет):
https://fipi.ru/oge/demoversii-specifikacii-kodifikatory

Когда ФИПИ опубликует окончательную версию, сверьте раздел «Об экзамене» и описания разделов в `js/data.js` (поле `note` у каждого раздела).

## Как открыть у себя

Двойной щелчок по `index.html`. Ничего устанавливать не нужно.

## Как поменять промпты и план

Всё содержимое — в **`js/data.js`**:

- `window.PROMPTS` — готовые промпты (схема та же, что в ИИ-Шпаргалке: `id`, `title`, `summary`, `section`, `help`, `duration`, `template`, `fields`, `tips`, `example`);
- `window.FIELDS` — разделы, кнопки конструктора, «Доработать ответ ИИ»;
- `window.PLAN` — пункты плана подготовки;
- `window.LINKS` — ссылки на нейросети и ФИПИ.

После правки обновите страницу. Если добавили новый файл — впишите его в `sw.js` (список `FILES`) и увеличьте `VERSION`.

## Как обновить сайт в интернете

Изменения загружаются в репозиторий `shpargalka-ai/oge-english` на GitHub — через минуту-две они появятся по той же ссылке.

## Важно

- Ученица и сайт хранят отметки только в браузере (`localStorage`, префикс `ogeen:`), без регистрации и аналитики.
- Нейросеть может ошибаться — на сайте это повторяется в нескольких местах, а для проверки есть чек-лист.
